pintrest 流式布局
----------------

**角色与目标：**
你是一位经验丰富的前端开发专家，精通 HTML、CSS 和 JavaScript。你的任务是创建一个视觉上精美、功能齐全的网页，其布局和风格与我提供的 Pinterest 页面截图高度相似。你需要注重代码的整洁性、响应式设计和现代前端开发实践。

**核心功能与页面结构：**

1.  **整体布局**：
    *   采用三段式布局：一个固定的左侧导航栏，一个顶部搜索栏，以及一个占据主要区域的内容展示区。
    *   页面背景色为浅灰色或白色，营造简洁、干净的视觉感受。

2.  **左侧导航栏 (Sidebar)**：
    *   **固定定位**：该导航栏在页面滚动时应始终保持在左侧可见位置。
    *   **图标按钮**：
        *   最上方是 Pinterest 的 Logo 图标（可以使用一个红色的圆形作为占位符）。
        *   下方是两个主要的导航按钮：“主页 (Home)” 和 “创建 (Create)”，请使用清晰、简约的图标来表示它们 (例如，一个房子的图标代表主页，一个加号的图标代表创建)。
        *   当鼠标悬停在按钮上时，应有背景色变灰的视觉反馈效果。

3.  **顶部搜索栏 (Header/Search Bar)**：
    *   **宽度**：搜索栏应占据页面顶部的绝大部分宽度，但与左侧导航栏和右侧用户区保持适当间距。
    *   **样式**：具有圆角矩形的形状，内部包含一个搜索图标和“搜索”字样的占位符文本。背景色为浅灰色，以区别于页面背景。
    *   **功能**：这是一个纯视觉展示，暂时不需要实现搜索功能。

4.  **右上角用户区**：
    *   **组件**：包含一个消息通知图标、一个个人主页图标，以及一个显示用户头像的圆形图标。
    *   **用户头像**：使用 `assets/images/avatar.jpeg` 作为用户头像图片。
    *   **交互**：点击圆形用户头像后，应弹出一个下拉菜单面板。
    *   **下拉面板**：
        *   面板样式应简洁，带有轻微的阴影效果。
        *   面板内容需模拟截图，包含当前登录的用户信息（如头像、用户名 "ka molotov"、邮箱地址）、"Convert to business" 链接以及 "Add Pinterest account" 和 "Log out" 等操作选项。
        *   下拉面板中的用户头像也使用 `assets/images/avatar.jpeg`。

5.  **内容区：卡片瀑布流 (Masonry Grid)**：
    *   **核心布局**：这是页面的视觉核心。请使用 CSS Grid 或 Flexbox，结合 JavaScript（如果需要的话）来实现一个动态的、多列的瀑布流布局。卡片应自动排列，填补可用空间，避免在底部出现大的空白。
    *   **卡片设计 (Card)**：
        *   每张卡片代表一个 "Pin"，主要内容是一张图片。
        *   卡片具有圆角，鼠标悬停在卡片上时，图片会有一个轻微的半透明黑色遮罩效果，并可能显示一些操作按钮（如“保存”、“分享”等，此部分可简化）。
        *   图片下方可以预留空间用于显示标题或描述，但这部分可以简化处理，主要突出图片本身。
    *   **响应式设计**：瀑布流的列数应根据屏幕宽度的变化而自适应调整。在宽屏上显示 10 列，在平板上显示 5 列，在手机上显示 2 列。
    *   **图片内容**：
        *   所有瀑布流图片位于 `assets/thumb/` 文件夹中。
        *   图片文件名为 `1.jpg` 到 `100.jpg` 共 100 张图片。
        *   请使用 JavaScript 自动加载这 100 张图片（从 `assets/thumb/1.jpg` 到 `assets/thumb/100.jpg`），并动态生成卡片元素将它们全部展示在瀑布流中。
        *   无需使用外部图片服务，所有图片都从本地加载。

**技术栈与要求：**

*   **HTML**: 使用语义化的 HTML5 标签。
*   **CSS**:
    *   请使用现代 CSS 技术，如 Flexbox 和 Grid 布局。
    *   无需依赖任何大型 CSS 框架（如 Bootstrap），请手写 CSS 来实现精确的样式控制。
    *   请将 CSS 写在 `<style>` 标签内，方便直接在浏览器中预览。
*   **JavaScript**:
    *   使用原生 JavaScript (Vanilla JS) 来实现必要的交互功能，特别是瀑布流布局的计算和右上角下拉菜单的点击切换。
    *   确保代码简洁易懂，并添加必要的注释。

**最终产出：**
请将所有 HTML、CSS 和 JavaScript 代码整合到一个单一的 `.html` 文件中，以便我可以直接复制并在浏览器中打开查看最终效果。
