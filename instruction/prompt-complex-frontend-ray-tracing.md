全局光照物理路径追踪 (时间冻结定格版)
----------------------------------
(CC-BY-NC-SA 4.0 by karminski-牙医)



**角色设定**：
你是一位曾参与过离线渲染器开发，且极其精通 WebGL 2.0、Three.js 底层以及 Cannon.js 物理引擎的顶级图形学大神。

**核心任务**：
编写一个单页面 HTML 文件，结合 Cannon.js 物理引擎，**完全使用 Fragment Shader 实现一个支持真实物理材质（PBR）和蒙特卡洛路径追踪（Monte Carlo Path Tracing）的动态坍塌场景**。
严禁使用 Three.js 的原生材质和灯光组件，一切光照必须在自定义着色器中通过解渲染方程（Rendering Equation）完成。

**场景与物理构成（Cannon.js 端）**：
1. 有限平面地面：一个尺寸为 `100 x 100` 的棋盘格平面。
2. 砖块墙壁：一面由 `1 x 2 x 4` 砖块交错错落堆叠构成的墙壁，总共由 100 块砖构成。
3. 动态球体 A（主光源）：一个高质量的发光球体 A，带有巨大的初速度，贴地滚动撞向墙体，引发真实的物理连锁坍塌。
4. 静态球体 B（辅助光源）：另一个高质量的发光球体 B，静止放置在墙壁的后方。

**材质与数据结构（CPU->GPU 同步挑战）**：
砖块分为三种材质：**粗糙黄金**、**毛玻璃（透射带粗糙度）**、**漫反射白墙**。
你必须在 JS 端将每块砖的 `逆世界矩阵`（16 float）以及 `PBR材质参数`（albedo, roughness, metallic, transmission 等，至少 4 float）打包成一维 `DataTexture` 传入 GPU。必须保证 Shader 中的解析绝对精准！

**光线追踪核心算法（Shader 端，极度硬核）**：
1. **PBR 与 BRDF**：必须实现 Schlick 菲涅尔近似、基于 GGX 微表面分布的粗糙度重要性采样（Importance Sampling），以及纯漫反射的余弦加权半球采样。必须体现出**粗糙度导致的高光模糊**。
2. **全局光照与软阴影**：引入 `dat.gui` 或 `lil-gui` 提供一个悬浮控制面板，需包含以下动态调节项，并实时同步给 Shader 的 Uniforms：
   - **最大光线反弹次数 (Max Bounces)**：范围 1~60，默认 3。
   - **单帧采样率 (SPP per frame)**：范围 1~100，默认 10。
   - 必须体现出光线在黄金、玻璃和地面之间的相互漫反射（Color Bleeding）。发光球体 A 和 B 作为 Area Light，必须产生真实的物理软阴影。
3. **环境光**：如果光线飞向远方，必须采样一个程序化的天空穹顶（如上蓝下暖的渐变）提供基础 GI 照明。
4. **空间矩阵运算**：在 Shader 中读取砖块的逆矩阵转换到 Local Space 求 OBB 相交后，**必须正确计算伴随矩阵（或逆转置矩阵）将局部法线转换回世界空间**。

**渐进式累积与去噪系统（核心定格逻辑！）**：
想要获得影视级画质，完全依赖于时间累积和无偏蒙特卡洛积分。你必须使用 `WebGLRenderTarget` 实现 **Ping-Pong 历史帧混合累积**，并遵循以下严格的触发逻辑：
- **时间冻结触发（重要！）**：演示开始时，开启计数器, 20s后 **立刻停止调用 Cannon.js 的 `world.step()`**，彻底冻结物理世界，形成“灾难定格”的画面。
- **动态期（重置累积）**：在物理世界冻结前，或者当相机 `OrbitControls` 正在被拖拽时，向 Shader 传入 `u_accumulateWeight = 0.0`，重置 `historyFrames = 0.0`。
- **静止期（疯狂累积）**：当物理世界已冻结，且相机交互停止时，向 Shader 传入真正的积分权重 `u_accumulateWeight = historyFrames / (historyFrames + 1.0)` 开始无限累加，并将 `historyFrames` 递增。
- **防噪点死锁机制**：必须确保 Fragment Shader 中生成随机数的种子（Seed）包含 `u_frameCount` 和像素坐标，保证每一帧发射的光线路径绝对随机，从而在静止累积期间，能在几秒内将噪点“洗”成完美无瑕的 CG 级大片！

**输出要求**：
直接输出一个极度干净、注释完善的 HTML。所有 PBR 数学公式、蒙特卡洛随机数生成器、矩阵求交部分必须有详细的中文原理解释。展现你作为顶尖图形开发者的实力！
