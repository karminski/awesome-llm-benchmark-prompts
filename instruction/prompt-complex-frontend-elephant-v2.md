大象牙膏v2
-----------

请使用 three.js 实现一个逼真的"大象牙膏"化学实验3D演示。所有代码（包括HTML, CSS, JavaScript）都必须封装在一个独立的HTML文件中。

**场景设置：**
1. **背景：**
    * 顶部蓝色向粉色渐变的晨曦效果天空盒
2.  **平面：** 创建一个尺寸为1000*1000的灰色、光滑的水平平面它能接收阴影。
3.  **锥形瓶：**
    *   **形状：** 在平面中心放置一个透明的玻璃锥形瓶。烧瓶应具有清晰的轮廓：圆润的瓶口，圆柱形的颈部、逐渐变宽的圆锥形瓶身和扁平的底部。请勿使用简单的圆锥体代替。
    *   **材质：** 烧瓶材质应为高度透明的玻璃，具有适当的高透射率，较低的粗糙度，以及正确的折射率来模拟玻璃。应能看到背景和透过液体的光线折射效果。
    *   **液体：** 烧瓶内预先装有约三分之一高度的荧光粉色液体。液体表面应平整，并与烧瓶内壁贴合。注意参考锥形瓶建模的形状，理想的做法是复制锥形瓶的部分锥形的形状，不要让液体建模溢出锥形瓶。
    *   **注意：** 锥形瓶的建模整个模型的方向朝向向上。

**"大象牙膏"喷发效果模拟：**
1.  **触发：** 页面在footer的位置提供一个按钮点击后开始喷发。
2.  **泡沫形态与质感：**
    *   使用 2000 大小不一的荧光粉色泡沫粒子模拟实验。
    *   喷射出的泡沫应由**大量微小、半透明、能够相互融合的粒子**组成，模拟真实泡沫的**稠密和蓬松质感**，避免看起来像孤立的小球。颜色为荧光粉色，可以带有一些亮度变化以增加层次感。
    *   考虑使用一个简单的**噪点纹理**或程序化方式为泡沫粒子增加一些表面细节，使其看起来更像多孔的泡沫而非光滑球体。
3.  **喷射动态与流体模拟：**
    * **膨胀阶段：** 泡沫从瓶内的液面处产生，受反应气压驱动，向上（+Y轴）运动。
    * **边界限制：** 在瓶内上升过程中，粒子的坐标必须严格限制在烧瓶内壁的数学边界内：
        - 当 $y < 20$ 时，最大半径限制为 $R(y) = 10 - 0.4 \times y$。
        - 当 $y \ge 20$ 时，最大半径限制为 $R(y) = 2$。
        - 粒子与边界碰撞时应沿瓶壁向上滑动，绝不能穿透瓶身（穿模）。
    * **喷嘴加速效应（Nozzle Effect / Venturi Effect）：**
        - 随着瓶身变窄，流体受压。粒子的上升速度 $v_y$ 必须与该高度下截面积的倒数成正比（或与其成比例加速）。
        - 粒子形成泡沫柱向上喷发,
        - 当粒子进入瓶颈（$y > 20$）时，向上喷射的速度应达到峰值，从而在瓶口（$y = 30$）形成高初速、高压力的“喷射流（Jet）”。喷射初始高度至少达到烧瓶高度的 3 倍以上。
    *   **初期喷发：** 泡沫从烧瓶口猛烈向上喷出，形成一个持续上升的圆柱(紧密的泡沫堆积在一起形成柱状)。高度至少要有锥形瓶的3倍高度，泡沫住直到快达到最大高度的时候才开始分散，初始喷射速度和压力较大。
    *   **压力衰减：** 喷射的强度（速度和产生泡沫的速率）应随时间**逐渐减弱**，导致泡沫柱的高度和喷射距离逐渐减小，模拟化学反应物耗尽的过程。
    *   **粒子运动：** 粒子运动轨迹应模拟**基本的流体动力学影响**，而不仅仅是简单的抛物线。例如，粒子之间应有轻微的排斥力以模拟泡沫的膨胀感，或者在喷射主流周围有随机的速度扰动。整体受重力影响。
4.  **泡沫与环境交互及变形：**
    *   **重力与堆积：** 喷出的泡沫粒子受重力影响下落。当泡沫颗粒接触平面时，他们有一定的弹性, 会撞击后如同流体撞击到坚硬表面弹起, 然后在平面上摊开, 最后粒子内部的气体逐渐溢出, 它们应该**模拟受压变形的效果**，在垂直方向上被压扁，并在水平方向上略微扩展。
    *   **与瓶身的碰撞：**大量泡沫如果撞击到瓶身的话，也应该弹开，然后少部分的泡沫粒子由于表面张力挂在瓶壁上逐渐滑落或者特别小的粒子直接粘在了瓶身上。
    *   **堆积形态：** 落在平面上的泡沫应该能逐渐**堆积起来，形成一定厚度的覆盖层**，而不是消失。堆积的泡沫也应有类似的变形和融合效果。
5.  **液体减少：**
    随着喷发，锥形瓶内的液体液面逐渐下降，用来演示液体减少的效果。注意不是液体整体缩小，而是液体的顶部的面逐渐下降的效果。

**光照与渲染：**
1.  **光源：**
    *   设置一个主光源，以产生清晰的阴影。
    *   添加一个环境光以提亮场景暗部，确保没有纯黑区域。
2.  **阴影：** 启用渲染器的阴影贴图 。平面应能接收阴影，烧瓶和喷出的泡沫应能投射阴影。
3.  **反射与折射：** 烧瓶的材质应能展示出环境的微弱反射和光线透过液体及玻璃的折射。

**摄像机与控制：**
*   摄像机应从斜45度角俯视场景中心（锥形瓶所在位置），确保能清晰观察到整个喷发过程和最终堆积效果。
