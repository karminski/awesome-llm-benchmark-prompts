**主题：** 使用 Three.js 制作 RBMK 反应堆事故的电影级 3D 模拟动画

**参考说明：** 本 prompt 基于 RBMK-1000 反应堆的真实结构图片和切尔诺贝利事故资料编写。包括反应堆堆芯的垂直燃料通道布局、带有彩色标识的上层生物屏蔽盖板（Elena）、以及事故过程的物理学细节。

**角色：** 你是一位精通 Three.js、GLSL Shader（着色器）编写以及 WebGL 视觉特效的创意编程专家。

**目标：** 创建一个基于浏览器的 3D 动画序列，演示 RBMK 石墨反应堆从临界、失控到最终爆炸熔毁的过程。该演示用于警示教学，视觉效果需要严肃、震撼且具有物理真实感。

**技术栈要求：**
1.  **核心库：** 使用 `Three.js` (CDN 引入)。
2.  **动画库：** 使用 `GSAP` (GreenSock) 来编排复杂的动画时间轴。
3.  **后期处理：** 必须使用 `EffectComposer` 和 **UnrealBloomPass**，这是模拟核反应堆高能光效和高温热辐射的关键。
4.  **生成方式：** 所有模型（堆芯、盖板、控制棒）均通过代码程序化生成（Procedural Generation），**不要**加载外部模型文件，确保代码复制后即可直接运行。

**场景组成：**

1.  **堆芯 (The Core)：** 
    *   **整体结构：** 由大量垂直的圆柱体（燃料通道）组成的矩阵，排列成约 18x18 的网格阵列（参考 RBMK-1000 的实际布局）。
    *   **燃料通道：** 每个通道是高耸的管状结构，贯穿整个堆芯高度。初始为深灰/黑色金属质感。
    *   **石墨慢化剂：** 在燃料通道之间填充深色石墨块（可用低多边形立方体表示），形成蜂窝状结构。
    *   **控制棒通道：** 散布在燃料通道中的垂直管道，用深蓝或银色材质区分。初始状态下，控制棒部分插入。
    *   **底部支撑结构：** 包含金属网格和管道，呈现工业机械美感。
    *   **高度：** 堆芯整体高度应为直径的 2-3 倍，突出其垂直特征。

2.  **上层生物屏蔽 (The Lid/"Elena")：** 
    *   **形状与尺寸：** 巨大的圆形混凝土盖板，直径覆盖整个堆芯（约 15-17 米），厚度约 2-3 米。
    *   **盖板组件：** 顶面由数百个方形/矩形的金属盖板拼接而成（模拟燃料装卸孔盖），每个盖板约 25x25cm。
    *   **颜色标识：** 盖板表面有不同颜色的标记：
        -   绿色：正常燃料通道
        -   黄色：控制棒位置
        -   红色：高功率区域
        -   蓝色：测量仪器位置
    *   **编号标签：** 在盖板边缘显示白色或黄色的位置编号（如 E31、K23 等），模拟实际的定位系统。
    *   **材质：** 表面应呈现粗糙的混凝土/金属混合质感，带有工业污渍和使用痕迹。
    *   **结构细节：** 边缘有明显的加强环和支撑梁。

3.  **中间层结构：**
    *   **水-蒸汽管道：** 从堆芯侧面延伸出的巨大管道（直径 1 米左右），连接到分离器-蒸汽发生器。
    *   **仪表穿透孔：** 在盖板和堆芯之间有细小的管道和线缆。

4.  **环境：** 
    *   **照明：** 黑暗的工业厂房，只有微弱的应急照明（冷白色或黄色）。
    *   **大气效果：** 轻微的蒸汽雾气和灰尘颗粒在空中漂浮。
    *   **背景：** 隐约可见的混凝土墙壁、管道和工业设备轮廓。

**动画剧本 (分阶段)：**
请编写一个名为 `startSequence()` 的主函数，利用 GSAP Timeline 按顺序执行以下阶段：

*   **阶段 0：初始状态 (Initial State)** *(持续 2-3 秒)*
    *   相机缓慢环绕堆芯旋转，展示整体结构。
    *   堆芯发出微弱的蓝绿色辉光（低功率运行状态）。
    *   盖板上的颜色标识清晰可见。
    *   环境音效：低沉的嗡嗡声、冷却水流动的声音（可选）。

*   **阶段 1：临界失控 (Criticality Runaway)** *(持续 5-8 秒)*
    *   **控制棒动作：** 所有控制棒（银色圆柱）快速向下插入燃料通道（AZ-5 按钮触发），插入速度约 0.4m/s。
    *   **末端效应开始：** 
        -   堆芯**底部区域**的燃料通道开始从蓝色转为橙红色。
        -   颜色从下向上逐渐蔓延，形成明显的温度梯度。
        -   石墨块开始发出暗红色的热辐射。
    *   **功率尖峰：** 
        -   堆芯亮度急剧增加，契伦科夫蓝光被红光压制。
        -   燃料通道表面开始产生热扭曲效果（使用折射 Shader）。
        -   盖板上的红色标记区域开始闪烁警告。
    *   **相机震动：** 轻微抖动开始，逐渐加剧。
    *   **声音提示：** 金属应力的嘎吱声、蒸汽管道的尖啸声。

*   **阶段 2：第一次蒸汽爆炸 (First Steam Explosion)** *(持续 2-3 秒)*
    *   **盖板破裂：** 
        -   盖板中央的几个组件首先被蒸汽压力顶起（模拟燃料通道盖的破裂）。
        -   随后整个 Elena 盖板（2000 吨重）被猛烈向上抛起，高度约 10-15 米。
        -   盖板在空中翻转约 30-45 度角，最后竖立在堆芯旁边或砸回堆芯上。
    *   **粒子效果：**
        -   从破裂处喷出的白色高压蒸汽柱（温度 1000°C+）。
        -   向上喷射的金属碎片、混凝土块和石墨碎屑。
        -   火红色的燃料碎片被抛到空中，拖着发光的尾迹。
    *   **光效变化：**
        -   蓝光瞬间被刺眼的白光/黄光取代。
        -   Bloom 强度急剧增加至 3-5 倍。
        -   产生强烈的镜头眩光效果（Lens Flare）。
    *   **冲击波：** 
        -   一圈半透明的冲击波从堆芯向外扩散。
        -   周围的雾气被吹散。
    *   **相机：** 剧烈震动，模拟冲击波冲击。

*   **阶段 3：第二次爆炸与空气接触 (Graphite Fire Ignition)** *(持续 3-5 秒)*
    *   **石墨燃烧：** 暴露的石墨慢化剂与空气接触后开始燃烧。
        -   石墨块从暗红色转为明亮的橙黄色火焰。
        -   产生大量黑色/灰色的浓烟（放射性石墨尘埃）。
    *   **第二次爆炸：** 氢气和一氧化碳爆燃，产生更大的火球。
    *   **火焰粒子：** 从堆芯向上喷涌的火焰和火星，高度达 30-50 米。
    *   **辐射光效：** 
        -   添加紫外线般的诡异光晕。
        -   空气中出现"电离辉光"效果（淡紫色/蓝白色）。

*   **阶段 4：堆芯熔毁 (Core Meltdown)** *(持续 8-12 秒)*
    *   **结构崩塌：** 
        -   失去支撑的燃料通道开始向中心倾斜、弯曲、断裂。
        -   石墨块逐个塌落到堆芯底部。
    *   **温度着色器效果：**
        -   使用自定义 `ShaderMaterial`，设置 `uniform float temperature`（范围 600K - 3000K）。
        -   **颜色映射：** 
            -   600K-900K: 深红色（dull red）
            -   900K-1200K: 橙红色（bright red）
            -   1200K-1700K: 橙黄色（orange-yellow）
            -   1700K-2500K: 黄白色（yellow-white）
            -   2500K+: 刺眼的白色（incandescent white）
        -   材质从固态金属逐渐变为粘稠的熔融岩浆质感。
    *   **熔融物流动：**
        -   熔化的燃料、石墨和金属混合物（"Corium"象脚怪物材质）向下流动。
        -   使用 UV 滚动动画模拟岩浆流动纹理。
        -   熔融物堆积在底部，形成发光的"岩浆池"。
    *   **热扭曲：** 强烈的热空气上升流产生的视觉扭曲（折射效果）。
    *   **发光强度：** Bloom 效果持续保持在高强度，模拟核燃料的自发光。
    *   **余烬效果：** 从熔融物表面飘起的发光微粒。

*   **阶段 5：余波 (Aftermath)** *(持续 5-8 秒)*
    *   相机缓慢拉远，展示被摧毁的堆芯全貌。
    *   火焰和浓烟持续向上翻涌。
    *   底部的熔融物池继续发出橙红色的恐怖光芒。
    *   周围环境笼罩在放射性尘埃形成的雾霾中。
    *   逐渐淡出到黑屏，显示警示文字（可选）。

**代码输出要求：**
请提供一个**完整的、可运行的 HTML 单文件**。文件应包含：

1.  **HTML 结构和 CDN 引入：**
    *   Three.js (最新版本)
    *   GSAP (GreenSock) 动画库
    *   （可选）dat.GUI 用于调试参数

2.  **CSS 样式：**
    *   全屏黑色背景 (`body { margin: 0; background: #000; }`)
    *   Canvas 填充整个视口
    *   简洁的 UI 控制按钮样式

3.  **JavaScript 核心逻辑：**
    
    **初始化部分：**
    *   场景、相机（透视相机，FOV 60-75）、WebGL 渲染器初始化
    *   启用抗锯齿和阴影（如果性能允许）
    *   设置 EffectComposer 和 UnrealBloomPass（Bloom 强度可调）
    
    **几何体生成：**
    *   `createReactorCore()`: 生成 18x18 的燃料通道阵列（CylinderGeometry）
    *   `createGraphiteBlocks()`: 在通道间填充石墨块（BoxGeometry）
    *   `createControlRods()`: 生成控制棒（细长的 CylinderGeometry）
    *   `createBiologicalShield()`: 生成 Elena 盖板及其表面的彩色标记网格
    *   `createSteamPipes()`: 添加侧面的管道装饰（可选）
    
    **材质系统：**
    *   **自定义 ShaderMaterial** 用于燃料通道，必须包含：
        -   `uniform float uTime`: 时间变量
        -   `uniform float uTemperature`: 温度变量（600-3000）
        -   `uniform vec3 uBaseColor`: 基础颜色
        -   Fragment Shader 实现温度到颜色的映射（黑体辐射）
        -   可选：添加 noise 函数模拟表面纹理和热扰动
    *   **标准材质** 用于石墨、混凝土、金属等
    
    **粒子系统：**
    *   蒸汽粒子：白色、半透明、向上运动、带有扩散
    *   碎片粒子：各种颜色、抛物线运动、带旋转
    *   火焰粒子：橙黄色、发光、湍流运动
    *   烟雾粒子：黑灰色、不透明度变化、缓慢上升
    
    **动画时间轴：**
    *   `startSequence()`: 主函数，使用 GSAP Timeline 串联所有阶段
    *   每个阶段使用 `timeline.to()` 控制各种属性：
        -   材质的 `uTemperature`、`emissive`、`opacity`
        -   物体的 `position`、`rotation`、`scale`
        -   相机的 `position`、抖动效果
        -   Bloom 的 `strength`、`threshold`、`radius`
    
    **用户界面：**
    *   简单的 HTML 按钮：`<button id="startBtn">Start Simulation</button>`
    *   （可选）dat.GUI 面板，可调节：
        -   Bloom 强度
        -   动画速度
        -   相机视角
        -   温度范围
    
    **性能优化：**
    *   使用 InstancedMesh 渲染重复的燃料通道和石墨块
    *   合理控制粒子数量（建议 1000-5000）
    *   使用 LOD（Level of Detail）技术（可选）

4.  **注释要求：**
    *   代码中关键部分必须有英文注释
    *   每个动画阶段开始前注释说明
    *   Shader 代码必须详细注释

**视觉基调：** 
*   黑暗、高对比度、危险的工业灾难风格
