# Role
你是一位精通Python和计算机图形学的资深游戏开发者，特别擅长使用Pygame进行物理模拟和算法可视化。

# Goal
请编写一个完整的Python脚本，使用 `pygame` 库实现一个流体寻路演示Demo。

# Requirements

## 1. 窗口与环境设置
- 窗口分辨率：1920x1080。
- 背景色为黑色，帧率限制为60FPS。
- 能够在脚本开头定义一个 `SEED` 变量，用于随机数生成器，确保迷宫生成的确定性。

## 2. 迷宫生成
- 使用 **递归回溯算法 (Recursive Backtracker)** 生成一个 5x5 的完美迷宫（保证所有路径连通）。
- 迷宫需要自动缩放以适应屏幕中间的大部分区域（留出边距）。
- **入口**：在迷宫顶部的墙壁随机选取一个位置打开缺口。
- **出口**：在迷宫底部的墙壁随机选取一个位置打开缺口。
- 渲染时，墙壁使用白色矩形绘制。

## 3. 流体粒子系统 (重点)
- 在迷宫入口处持续生成圆形粒子（模拟水流），颜色为蓝色（可以使用深浅不同的蓝色增加视觉效果）。
- **物理模拟**：
  - 粒子受到重力影响向下加速。
  - 粒子之间需要有简单的排斥力或体积碰撞，以防止无限重叠，模拟液体的“堆积”效果。
  - 粒子与迷宫墙壁发生碰撞时需要反弹或滑落。
- **目标**：水流应自然地填充死路，并最终找到路径从底部出口流出。

## 4. 性能优化 (关键)
- 由于Python性能限制，请务必实现 **空间哈希网格 (Spatial Hash Grid)** 或 **统一网格 (Uniform Grid)** 算法来处理碰撞检测。
  - **严禁**使用 O(N^2) 的双重循环进行全粒子对撞检测。
  - 仅检测同一网格或相邻网格内的粒子/墙壁。
- 请合理控制最大粒子数量（例如上限1500-2000个），当超出屏幕下方或超出数量限制时回收旧粒子。

## 5. 代码结构
- 代码需要封装在类中（例如 `Particle`, `Maze`, `Simulation`）。
- 包含清晰的注释解释物理计算和碰撞算法的逻辑。
- 启动脚本后，直接开始演示。

请给出完整、可直接运行的代码。
