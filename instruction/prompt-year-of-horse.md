串鞭炮燃放与马年吉祥物3D演示
-------------------------------

(CC-BY-NC-SA 4.0 by karminski-牙医)

请使用 three.js 实现一个逼真的"串鞭炮燃放"3D 演示。所有代码（包括 HTML, CSS, JavaScript）都必须封装在一个独立的 HTML 文件中。场景展现一串悬挂在半空中的中式传统鞭炮被点燃后依次燃放的全过程，最终从顶部八角盒子中掉出一个马年吉祥物。

---

## 1. 技术栈要求

*   **核心库：** Three.js (r150+ via CDN)
*   **交互：** OrbitControls (支持平滑阻尼)
*   **动画：** 使用 `requestAnimationFrame` 配合 `THREE.Clock`
*   **后处理：** `EffectComposer`, `RenderPass`, `UnrealBloomPass`
*   **SVG 加载：** `SVGLoader`（用于解析马年吉祥物的 SVG 轮廓）
*   **建模方式：** 纯代码程序化生成（鞭炮、八角盒子等）；马年吉祥物通过加载外部 SVG 文件 `horse-4-svgrepo-com.svg`（与 HTML 文件同目录）解析轮廓后挤出为 3D 几何体

## 2. 场景与环境设置

*   **背景：**
    *   使用 CanvasTexture 创建径向渐变背景。
    *   中心颜色：深红色偏暖 (`#4A0000`)。
    *   边缘颜色：近黑的暗红 (`#1A0000`)。
    *   营造喜庆、热烈的春节氛围。

*   **地面：**
    *   创建一个尺寸为 80×80 的水平平面。
    *   材质使用 `MeshStandardMaterial`：`{color: 0x555555, roughness: 0.85, metalness: 0.1}`。
    *   接收阴影 `receiveShadow = true`。

*   **光照系统：**
    *   **环境光 (AmbientLight)：** 强度 0.5，颜色暖白 (`#FFF5E6`)，确保场景无纯黑区域。
    *   **主光源 (DirectionalLight)：** 位于右上方 45 度角，强度 1.0，暖色 (`#FFEEDD`)，开启阴影 `castShadow = true`，阴影贴图分辨率 1024。
    *   **补光 (DirectionalLight)：** 位于左后方，强度 0.3，冷色调 (`#AABBFF`)，不投射阴影。
    *   **性能约束：动画过程中不创建动态点光源。所有火光效果用自发光材质 (emissive) + Bloom 后处理实现，而非添加新的光源。**

*   **色调映射：** 使用 `THREE.ACESFilmicToneMapping`，曝光 `renderer.toneMappingExposure = 1.0`。

## 3. 鞭炮串模型详细规范

整体结构：一根竖直的主引线，左右两侧交错排列各 50 个鞭炮（共 100 个），顶部悬挂一个八角盒子，底部主引线留出一段约 2 单位的空白用于点火。整体悬挂在场景中央偏上的位置，底部距离地面约 8 单位。

### 3.1 主引线 (Main Fuse)

*   **外形：** 竖直的红褐色绳索，总长约 30 单位。使用多段 `TubeGeometry` 沿直线路径构建，半径 0.06。
*   **材质：** `{color: 0x8B4513, roughness: 0.9, metalness: 0.0}`。
*   **结构分段：** 主引线在逻辑上分为 100 个区段，每个区段对应一个鞭炮的连接点。左侧鞭炮连接奇数段，右侧鞭炮连接偶数段，形成交错排列。
*   **底部留白：** 主引线最底部留出约 2 单位长度，无鞭炮连接，作为点火区域。
*   **燃烧表现：** 主引线从底部向顶部逐渐燃烧。已燃烧段先短暂变为深灰黑色 `{color: 0x222222, emissive: 0x331100}`，然后在 0.3 秒内 `opacity` 渐变为 0 并隐藏（`visible = false`），**已燃烧的主引线段必须消失不可见，不能残留在场景中**。燃烧前端有一个橙红色发光点（使用 `emissive: 0xFF4400, emissiveIntensity: 3.0` 的小球体），依靠 Bloom 产生火光效果。主引线材质需设置 `transparent: true` 以支持 opacity 渐变。

### 3.2 单个鞭炮 (Individual Firecracker)

*   **主体：** 红色圆柱体，高度 0.8，直径 0.18。
    *   材质：`{color: 0xCC0000, roughness: 0.5, metalness: 0.15}`。
*   **封土：** 圆柱体顶部和底部各一个土黄色小圆柱，高度 0.04。
    *   材质：`{color: 0xDAA520, roughness: 0.8}`。
*   **引线（支线）：** 从鞭炮顶部封土伸出的蓝绿色细圆柱，长度 0.4，直径 0.03，连接到主引线。
    *   材质：`{color: 0x20B2AA, roughness: 0.4}`。
*   **排列方式：** 主引线左侧的鞭炮引线从右侧伸出连接主引线，右侧反之。每个鞭炮与主引线间距约 0.3 单位。上下鞭炮间距约 0.25 单位。
*   **物理属性：** 每个鞭炮具有质量、位置、速度、角速度属性，用于脱落后的物理模拟。

### 3.3 八角盒子 (Octagonal Box)

*   **位置：** 悬挂在主引线最顶部。
*   **外形：** 正八边形柱体，宽度约 3 单位，高度约 2.5 单位。使用 `CylinderGeometry(radius, radius, height, 8)` 构建八边形。
*   **主体材质：** 鲜红色，`{color: 0xBB0000, roughness: 0.4, metalness: 0.3}`。
*   **金色花纹装饰：**
    *   顶部和底部边缘各有一圈金色装饰条（使用略大的八边形薄片叠加），`{color: 0xFFD700, roughness: 0.2, metalness: 0.9}`。
    *   盒体侧面的每个面上有金色的菱形或圆形装饰图案（使用贴合的扁平几何体实现）。
*   **底部缝隙：** 盒子底部留有一圈可见的细缝（视觉缝隙即可），用于后续烟花喷射效果。
*   **悬挂绳：** 从盒子顶部向上延伸一根红色绳子，绳子顶端固定在场景上方不可见的悬挂点。

## 4. 动画流程

### 阶段零：静态展示

*   页面加载后展示完整的鞭炮串悬挂在半空中的静态画面。
*   页面底部居中显示一个红底金字的"开始燃放"按钮，按钮样式需要有中国新年风格（圆角、金色边框）。
*   摄像机从侧面 30 度角观察整串鞭炮，可鼠标拖拽旋转。

### 阶段一：点火与主引线燃烧 (约 0-2 秒)

1.  点击按钮后，按钮消失。
2.  主引线底部出现一个火星发光点，开始向上匀速燃烧。
3.  **燃烧速度：** 主引线的燃烧速度必须是单个鞭炮支线引线燃烧速度的 **3 倍**。鞭炮支线引线长度 0.4 单位、燃烧时间 0.3 秒（即 1.33 单位/秒），因此主引线燃烧速率为 **4 单位/秒**，主引线总长约 30 单位，总燃烧时间约 **7.5 秒**（从底部到顶部八角盒子）。这个较快的速度能让鞭炮密集快速地脱落，产生"噼里啪啦四散"的热闹效果。
4.  火星点使用高 emissive 球体 + Bloom 实现发光效果，不使用动态点光源。
5.  主引线已燃烧部分逐段变灰变黑，随后在 0.3 秒内 opacity 渐变为 0 并隐藏消失（与 3.1 节描述一致）。

### 阶段二：鞭炮依次脱落与燃放 (约 2-10 秒)

当主引线燃烧到某个鞭炮的连接点时：

1.  **引线点燃：** 该鞭炮的支线引线被点燃，引线顶端出现火星发光点，引线在 0.3 秒内从连接端向鞭炮端缩短燃烧。
2.  **脱落：** 引线燃烧到连接处时，鞭炮从主引线上断开，开始自由落体。
    *   脱落时给予鞭炮一个随机的微小水平初速度（±0.5 单位/秒），使其不完全竖直下落。
    *   鞭炮在下落过程中有随机翻滚旋转。
3.  **弹性碰撞：** 鞭炮落到地面时产生弹性碰撞。
    *   弹性系数 0.3-0.5（不完全弹性）。
    *   碰撞后弹起高度逐次衰减。
    *   鞭炮之间也有简单碰撞检测，爆炸冲击波可以推开附近的未爆鞭炮。
4.  **爆炸：** 鞭炮的引线完全燃尽后（距脱落约 0.8-1.2 秒随机延迟），鞭炮爆炸：
    *   鞭炮模型瞬间消失。
    *   产生一个 emissive 高亮球体快速膨胀后消失（持续 0.15 秒），模拟爆炸闪光。
    *   **碎屑系统（性能优化版）：** 使用 **单个 `InstancedMesh`** 管理所有碎屑。每次爆炸产生 **8-12 个**红色小碎片（远少于旧版 prompt 的 50-80 个）。碎片受重力掉落，落地后 3 秒内逐渐透明消失并从实例池中回收复用。
    *   **烟雾：** 爆炸位置产生 3-5 个灰白色半透明球体，缓慢上升并放大，2 秒内 opacity 渐变为 0 后回收。使用 `InstancedMesh` 或对象池。
5.  **冲击效果：** 爆炸产生的冲击力范围 1.5 单位，将范围内其他已落地但未爆的鞭炮弹开。
6.  **节奏：** 左右鞭炮交替点燃，整体产生"噼里啪啦"的密集节奏感。相邻鞭炮点燃间隔约 0.075 秒（与主引线 3 倍速燃烧匹配，100 个鞭炮在约 7.5 秒内全部点燃）。

### 阶段三：八角盒子燃放烟花 (约 10-17 秒)

当主引线燃烧到八角盒子底部时：

1.  **盒子底部喷火：** 八角盒子底部缝隙开始冒出火光。
    *   使用向下喷射的粒子系统（InstancedMesh），粒子为金色小球 `{color: 0xFFD700, emissive: 0xFFAA00, emissiveIntensity: 2.0}`。
    *   粒子初始向下喷出，受重力影响呈抛物线轨迹散开，模拟烟花金星效果。
    *   持续喷射约 5 秒，期间粒子强度先增后减。
2.  **金色星星喷射：**
    *   从盒子底部喷出的粒子形成扇形散射。
    *   每帧生成 3-5 个粒子，粒子带有拖尾效果（通过逐帧降低旧粒子亮度实现）。
    *   粒子在飞行 1-2 秒后渐隐消失并回收。
3.  **盒子轻微晃动：** 喷射期间盒子产生微弱的随机振动（位移幅度 ±0.05 单位），模拟喷射反冲力。

### 阶段四：马年吉祥物掉出 (约 17-22 秒)

烟花喷射结束后：

1.  **盒子底部打开：** 盒子底部的一块板缓慢向下翻开（约 0.5 秒）。
2.  **吉祥物掉出：** 一个马造型的吉祥物从盒子中掉出。
    *   **吉祥物建模（基于 SVG 挤出）：**
        *   使用 `SVGLoader` 加载同目录下的 `horse-4-svgrepo-com.svg` 文件（fetch 获取 SVG 文本后交给 SVGLoader.parse 解析）。
        *   SVG 解析后得到的 paths 通过 `SVGLoader.createShapes()` 转换为 `THREE.Shape` 数组。
        *   对每个 Shape 使用 `ExtrudeGeometry` 沿 Z 轴挤出，赋予一定厚度（depth），使其成为一个有体积的 3D "浮雕"式马造型。
        *   开启 bevel（倒角），让边缘圆润光滑，呈现类似金属挂件或陶瓷摆件的质感。
        *   **材质：** 使用双面材质数组（`ExtrudeGeometry` 支持 material index）。正面和背面使用喜庆红色 `{color: 0xCC0000, roughness: 0.3, metalness: 0.4}`，侧面（挤出壁和 bevel 面）使用金色 `{color: 0xFFD700, roughness: 0.2, metalness: 0.8}`，形成红底金边的喜庆效果。
        *   **注意 SVG 坐标系转换：** SVG 的 Y 轴向下，Three.js 的 Y 轴向上，加载后需要将整个模型绕 X 轴翻转 180 度（`rotation.x = Math.PI`）以校正方向。
        *   **缩放与居中：** SVG 原始尺寸为 512×512，加载后需要计算 bounding box，将模型居中到原点，并统一缩放使整体高度约为 1.5 单位，以匹配场景比例。
    *   **悬挂绳：** 吉祥物顶部通过一根红色细绳（长度约 4 单位）连接到盒子内部的固定点。
3.  **钟摆运动：** 吉祥物掉出后，以绳子连接点为圆心做钟摆运动。
    *   初始角度约 60 度（从掉出方向获得的初始动量）。
    *   阻尼系数 0.98，摆动幅度逐渐减小。
    *   使用简谐运动公式：`angle = maxAngle * sin(time * frequency) * damping^time`。
    *   吉祥物在荡来荡去的过程中始终面朝摆动方向（通过旋转实现）。
4.  **最终定格：** 吉祥物最终在最低点附近缓慢停下，微微晃动。

## 5. 性能优化要求（关键）

由于此场景粒子和动态物体较多，必须严格控制性能：

1.  **碎屑与粒子统一管理：**
    *   所有爆炸碎屑使用 **一个** `InstancedMesh`（最大实例数 200）。碎屑消失后实例槽位回收复用。
    *   所有烟雾粒子使用 **一个** `InstancedMesh`（最大实例数 50）。
    *   烟花金星使用 **一个** `InstancedMesh`（最大实例数 100）。
2.  **禁止动态光源：**
    *   **不允许在动画过程中创建或销毁 `PointLight`。** 所有火光、爆炸闪光效果必须通过材质的 `emissive` 属性配合 `UnrealBloomPass` 后处理实现。
    *   这是解决前一版本卡顿问题的核心策略。
3.  **Bloom 设置：**
    *   阈值 (Threshold)：0.8。
    *   强度 (Strength)：0.6。
    *   半径 (Radius)：0.4。
    *   通过控制物体的 `emissiveIntensity`（2.0-5.0）来让火光"穿过"阈值产生辉光效果。
4.  **几何体优化：**
    *   鞭炮圆柱体分段数控制在 `radialSegments: 8`。
    *   地面不使用过高的细分。
    *   八角盒子装饰尽量用少量面片。
5.  **对象池 (Object Pool)：**
    *   鞭炮爆炸后，其 Mesh 不 `dispose()` 再重建，而是隐藏后放入对象池，以避免 GC 抖动。
    *   烟雾、碎屑全部使用 InstancedMesh 实例池模式。
6.  **阴影优化：**
    *   只有主方向光投射阴影。
    *   阴影贴图分辨率 1024（不要更高）。
    *   鞭炮碎屑和烟雾粒子不投射阴影。

## 8. 代码结构要求

*   创建 `Firecracker` 类管理单个鞭炮的状态（未燃、引燃、脱落中、已爆炸）和物理属性。
*   创建 `FirecrackerString` 类管理整串鞭炮的排列、主引线燃烧逻辑和依次引燃调度。
*   创建 `OctagonalBox` 类管理八角盒子的模型、烟花喷射和吉祥物释放。
*   创建 `ParticleManager` 类统一管理所有 InstancedMesh 粒子系统（碎屑、烟雾、烟花星星）。
*   创建 `HorseMascot` 类管理吉祥物的 SVG 加载、ExtrudeGeometry 挤出建模、材质设置、坐标系校正、缩放居中以及钟摆运动物理。
*   所有物理计算使用简化的欧拉积分，不引入外部物理引擎。
*   代码中添加简短的英文注释说明关键逻辑。
