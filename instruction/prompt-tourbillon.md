陀飞轮机芯3D演示 Prompt
------------------------

(CC-BY-NC-SA 4.0 by karminski-牙医)


**角色：** 你是一位精通 Three.js、WebGL 着色器以及精密钟表机械原理的创意编程专家。

**目标：** 创建一个基于浏览器的单文件 HTML 交互式 3D 场景，从零开始通过代码（Procedural Generation）构建一个机械原理准确的瑞士陀飞轮（Tourbillon）演示。

**主要修改说明：**
1.  **视觉风格：** 必须使用**浅蓝色与白色渐变**的明亮背景，营造现代、清新的实验室风格，而非传统的深色背景。
2.  **机械原理：** 必须遵循真实的**行星齿轮**运动逻辑：中心秒轮固定不动，陀飞轮框架绕其旋转，带动安装在框架上的擒纵轮自转。

---

## 1. 技术栈要求

*   **核心库：** Three.js (r150+ via CDN)
*   **交互：** OrbitControls (支持平滑阻尼)
*   **动画：** 使用 `requestAnimationFrame` 配合 `THREE.Clock`，可选 GSAP 用于特殊过渡。
*   **后处理：** `EffectComposer`, `RenderPass`, `UnrealBloomPass` (需针对亮背景微调).
*   **建模方式：** **纯代码生成** (使用 ExtrudeGeometry, LatheGeometry, TorusGeometry 等组合)，严禁加载外部模型。

---

## 2. 场景与环境设置 (亮色调适配)

*   **背景 (Background)：** 
    *   创建一个径向渐变纹理 (CanvasTexture)。
    *   中心颜色：纯白色 (`#FFFFFF`)。
    *   边缘颜色：清透的冰蓝色 (`#E0F7FA` 或 `#B2EBF2`)。
    *   效果：仿佛置身于明亮的制表工作室。
*   **光照系统 (Lighting)：**
    *   **重要原则：** 由于使用白色/浅蓝色明亮背景，光照强度必须克制。ACES 色调映射会压缩高光，过强的光照会导致金属表面过曝、细节丢失。
    *   **色调映射曝光：** `renderer.toneMappingExposure` 设置为 **0.85**，略低于默认值，避免亮背景下整体过曝。
    *   **环境光 (Ambient)：** 强度 **0.4**，颜色蓝白色 (`#F0F8FF`)，仅用于防止阴影死黑，不宜太高。
    *   **主光源 (Directional)：** 位于右上方，强度 **1.0~1.2**，产生清晰但不刺眼的高光，开启阴影 (`castShadow: true`)。
    *   **补光 (Point)：** 位于左后方，冷色调，强度 **0.4~0.6**，用于勾勒金属边缘。
    *   **阴影配置：** 阴影颜色不应是纯黑，而应是半透明的深灰蓝色，设置 `shadowMap` 分辨率为 2048。
*   **环境贴图 (Environment Map)：**
    *   **至关重要：** 在白色背景下，高反射金属（铬/钢）如果只反射白色会隐形。
    *   请使用 `THREE.PMREMGenerator` 生成一个虚拟的高对比度环境图（包含深灰和蓝色的色块），确保金属部件能反射出清晰的深色轮廓。
    *   **材质 `envMapIntensity`** 控制在 **0.7~1.0** 之间，不宜超过 1.0，避免反射过亮导致金属表面看不清。

## 3. 机械部件详细规范

请按以下层级构建模型，确保父子级关系正确以便于动画：

### 3.1 固定中心轮 (The Fixed Fourth Wheel) - [静止基准]
*   **位置：** 场景绝对中心 (0,0,0)。
*   **状态：** **绝对静止**，不随任何部件旋转。
*   **外形：** 较大的黄铜齿轮（约 60 齿）。
*   **材质：** 拉丝黄铜 (`color: 0xD4AF37`, `roughness: 0.3`, `metalness: 0.9`)。
*   **原理：** 它是“太阳轮”，陀飞轮框架绕它公转。

### 3.2 陀飞轮框架 (Tourbillon Cage) - [公转主体]
*   **层级：** 场景根节点的子对象。
*   **外形：** 经典的宝玑式三臂或双臂框架，线条优雅。
*   **材质：** 抛光钢 (`color: 0xAAAAAA`, `metalness: 1.0`, `roughness: 0.1`)，略带蓝色反光。
*   **动画：** 绕 Y 轴匀速旋转（公转），周期 60 秒/圈。
*   **包含部件：** 摆轮、擒纵叉、擒纵轮都安装在这个框架内。

### 3.3 擒纵轮组件 (Escape Wheel Assembly) - [行星运动]
*   **层级：** **陀飞轮框架**的子对象（随框架公转）。
*   **组成：**
    1.  **擒纵轮本体：** 独特的星状齿轮（约 15 齿），安装在轴上方。
    2.  **擒纵小齿轴 (Escape Pinion)：** 安装在轴下方，与 **3.1 固定中心轮** 啮合。
*   **位置：** 偏离中心，位于框架的一侧。
*   **材质：** 亮金色黄铜。
*   **动画逻辑 (核心)：** 
    *   无需手动编写旋转动画。
    *   由于它作为子对象随框架公转，且小齿轴与静止的中心轮啮合，视觉上应呈现出行星齿轮的自转效果。
    *   代码中可简化模拟：`rotation.y += time * speed`，但速度必须比框架快得多。

### 3.4 擒纵叉 (Pallet Fork)
*   **层级：** **陀飞轮框架**的子对象。
*   **位置：** 介于擒纵轮和摆轮之间。
*   **动画：** 做快速的往复摆动（Tick-Tock），频率约 4Hz。

### 3.5 摆轮与游丝 (Balance Wheel & Hairspring)
*   **层级：** **陀飞轮框架**的子对象。
*   **位置：** 占据框架的大部分空间。
*   **摆轮：** 带有配重螺丝的金色圆环，中心有辐条。
*   **游丝：** 
    *   **极细的蓝钢螺旋线** (`color: 0x2244CC`)。
    *   使用 `THREE.Line` 或极细的 `TubeGeometry` 构建阿基米德螺旋。
*   **动画：** 
    *   做简谐振动（正弦波运动）：`rotation = maxAngle * sin(time * frequency)`。
    *   游丝应随摆轮旋转产生“呼吸”般的收缩扩张效果（通过缩放实现）。

### 3.6 宝石轴承 (Jewels)
*   **材质：** 红宝石 (`color: 0xE91E63`)。
*   **特性：** 高透明度 (`transmission: 0.8`)，高折射率，但在亮背景下需增加一点 `emissive` 红色发光，确保鲜艳可见。
*   **位置：** 所有转轴的连接点。

## 4. 后期处理与特效

*   **Bloom (光晕)：**
    *   **阈值 (Threshold)：** 必须设置在 **0.90 - 0.95** 之间。
    *   **原因：** 背景是白色的，阈值太低会导致背景和大面积金属高光都产生 Bloom，使画面泛白模糊，看不清物体细节。阈值必须足够高，确保只有极亮的高光反射点产生微弱辉光。
    *   **强度 (Strength)：** **0.1 ~ 0.2** (非常轻微，仅起到画面柔和作用)。
    *   **半径 (Radius)：** 0.4。

---

## 5. 输出代码要求

1.  **HTML结构：** 提供一个完整的 index.html 文件，包含 CSS 重置（margin: 0, overflow: hidden）。
2.  **代码逻辑：**
    *   初始化场景、相机、渲染器。
    *   构建各部件函数：`createFixedWheel()`, `createCage()`, `createBalance()`, `createEscapement()`。
    *   **动画循环：** 在 `animate()` 中统一计算 `deltaTime`，确保各部件运动同步且流畅。
3.  **注释：** 关键数学计算和材质参数请添加简短中文注释。
4.  **性能：** 齿轮齿数适量优化，使用 `BufferGeometry`。
