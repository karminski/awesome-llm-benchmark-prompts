# 大模型性能测试 Prompts

一组用于测试大模型代码生成能力的炫酷 prompt 集合。

![](./assets/images/cover.png)

## 包含的测试场景

| Prompt | 描述 |
|--------|------|
| blow-water | 吹水效果 |
| car-crash | 汽车碰撞模拟 |
| elephant | 大象动画 |
| firecracker | 烟花爆竹效果 |
| fluid | 流体模拟 |
| hydroMaze | 水迷宫 |
| pintrest | Pinterest 风格布局 |
| RBMK-blow | RBMK 反应堆爆炸 |
| roche-limit | 洛希极限模拟 |
| rollercoaster | 过山车动画 |
| rubiks-cube | 魔方模拟 |
| seaball | 海球效果 |
| tourbillon | 陀飞轮机械表 |
| year-of-horse | 马年主题动画 |

## 用途

这些 prompt 主要用于评估大模型在复杂视觉效果、物理模拟、动画生成等方面的代码能力。
